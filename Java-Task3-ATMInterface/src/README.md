# ATM Interface

## 📌 Project Overview

This project is a console-based ATM Interface developed using Java.

The application simulates basic ATM operations such as user authentication, transaction history, cash withdrawal, cash deposit, and money transfer between accounts.

## 🎯 Objective

The objective of this project is to create a simple ATM simulation using Java and Object-Oriented Programming concepts.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Scanner
- Java Console

## ✨ Features

- User ID and PIN authentication
- Maximum 3 incorrect PIN attempts
- Transaction History
- Cash Withdrawal
- Cash Deposit
- Money Transfer
- Insufficient Funds validation
- Invalid menu choice handling
- Current balance display
- Multiple bank accounts
- Exit/Quit option
